# MD Manik Sheikh — GitHub Pages Website

## Publish as maniksheikh.github.io

1. Create/sign in to a GitHub account.
2. Create a new repository named exactly: `maniksheikh.github.io`
3. Upload `index.html` and the `assets` folder.
4. Go to Settings → Pages.
5. Under Build and deployment, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then Save.
7. Open: `https://maniksheikh.github.io`

Before publishing, replace the placeholder email/Facebook/LinkedIn links in `index.html` with your real links.
